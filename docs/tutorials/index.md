# Tutorials

Tutorials are lessons. They take you through a complete, working experience start to finish, so you
learn Dispatch by building something real. Follow the steps in order.

- [Getting started](../getting-started.md) — Build and run your first Dispatch terminal app: a
  config block, a composable screen, and a key binding to quit.
- [Build a navigated, stateful app](build-a-navigated-app.md) — Add a typed navigation back stack,
  an MVI view model, and Koin dependency injection to grow the starter app into a multi-screen app.

When you finish the tutorials, move on to the [how-to guides](../how-to/index.md) for specific
tasks, or the [reference](../reference/index.md) to look up exact APIs.
